#  Taste Hub - Recipe Sharing Web Application

Welcome to **Taste Hub**, a modern, fully responsive recipe-sharing web application developed as part of our academic web development assignment. This platform allows users to explore delicious recipes, manage user accounts, and interact with a culinary community.

---

##  Project Requirements & Implementation Overview

- **HTML Pages:** Built with multiple structured HTML pages (`index.html`, `recipes.html`, `login.html`, etc.) ensuring seamless navigation.
- **Styling & Components:** Styled completely using **Bootstrap 5** and custom CSS, incorporating professional components such as Navigation Bars, Cards, Carousels, and Modals.
- **Responsive Design:** Fully responsive layout optimized for mobile, tablet, and desktop viewports.
- **Global Navigation & Footer:** Consistent navigation bars and footers present across all pages for a cohesive user experience.

---

##  Core JavaScript Features

Our application implements three robust, professional JavaScript features to enhance interactivity and client-side logic:

1. **Password Visibility Toggle:**
   - Interactive DOM manipulation allowing users to show or hide their password input using an eye icon toggle on the authentication page.

2. **Dynamic Tab Switcher (Login & Register):**
   - Seamlessly switches between Login and Register views within a single interface modal/page without full reloads, dynamically updating headers, input groups, and buttons via a custom `switchTab` function.

3. **Comprehensive Form Validation & Error Handling:**
   - Robust client-side validation for authentication fields (Email format using RegEx, minimum password length check, and dynamic full-name validation for registrations) utilizing custom styled error messages and `preventDefault()` logic.

---

##  Technologies Used

- **HTML5** – Semantic structure
- **CSS3 & Bootstrap 5** – Responsive design and UI components
- **JavaScript (ES6+)** – Client-side interactivity, form validation, and DOM manipulation

##  Collaborative Workflow & Git Strategy

The project was developed collaboratively using a structured version control workflow:
- Maintained a shared **`main`** branch on GitHub as the central integration point.
- Used descriptive commit messages for feature updates, bug fixes, and layout enhancements.
- Performed rigorous testing using local development servers (`Live Server`) and synchronized code updates across partner environments using `git push` and `git pull`.
