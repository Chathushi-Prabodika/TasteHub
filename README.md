# TasteHub - Web Technologies Mini Project

Welcome to **TasteHub**, a web-based culinary platform developed as part of the ICT 1209 - Web Technologies course at the Department of ICT, Rajarata University of Sri Lanka.

---

## 1. Project Overview & Theme
* **Project Title:** TasteHub
* **Theme:** Recipe & Food Sharing Web Application
* **Purpose:** To provide a responsive, user-friendly platform where food enthusiasts can discover recipes, view detailed cooking instructions, and interact via contact features.

---

## 2. Purpose and Goals
* To deliver a clean, modern, and engaging interface for browsing diverse culinary recipes.
* To ensure full layout responsiveness across mobile, tablet, and desktop viewports using Bootstrap 5.
* To implement robust client-side form validation and interactive JavaScript features for enhanced user experience.

---

## 3. Target Audience
* Home cooks, food lovers, and individuals looking for quick, delicious, and easy-to-follow recipes.
* Students and users wanting to explore food blogs with an intuitive user interface.

---

## 4. Key Features
* **Consistent Layout:** Responsive navigation bar and footer integrated across all main pages.
* **Recipe Catalog:** Structured layout displaying multiple food categories and recipe items using Bootstrap components.
* **Interactive Contact & Support:** Contact page equipped with real-time client-side validation.
* **User Authentication Pages:** Dedicated login and registration interfaces.

---

## 5. Technology Stack
* **Markup Language:** HTML5
* **Styling & Design:** CSS3, Bootstrap 5, Bootstrap Icons
* **Client-Side Scripting:** JavaScript (Vanilla JS)
* **Version Control:** Git & GitHub

---

## 6. Implemented JavaScript Features
1. **Form Validation:** Real-time feedback, empty field checks, and email format verification on the contact and login forms.
2. **Dynamic Content Updates:** Interactive toggles and content management across recipe sections.
3. **Event Handling:** Custom click events, hover effects, and responsive navigation toggles.

---
